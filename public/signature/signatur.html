Gmail-Signaturen

Vorschau mit eingebetteten Bildern. „Kopieren“ legt die Version mit den gehosteten Bild-URLs in die Zwischenablage, die dann direkt in Gmail eingefügt wird.

English

So kommt sie in Gmail

  1. Die Dateien aus dem Ordner signature (photo-v2.png + icon-*.png) auf devnik.dev hochladen, bei Nuxt einfach nach public/signature/. Anderer Pfad? Oben die URL anpassen.
  2. Prüfen, dass z. B. https://devnik.dev/signature/photo-v2.png im Browser öffentlich lädt.
  3. Hier auf „Kopieren“ klicken.
  4. Gmail → Einstellungen → Alle Einstellungen → Signatur → „Neu erstellen“ → ins Feld einfügen (Cmd+V) → unten „Änderungen speichern“.
  5. Für die zweite Sprache eine zweite Signatur anlegen. Beim Schreiben wechselst du über das Stift-Symbol in der Mail-Leiste.
